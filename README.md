## 💫 About Me

Software Engineering student at the **National Institute of Telecommunications (INATEL)**, currently researching **indoor geolocation for visually impaired people** using Wi-Fi fingerprinting and Machine Learning (IC/Research project).

Passionate about building robust backend systems and applying AI/ML to solve real-world problems — from computer vision pipelines to embedded intelligence.

- 🔭 Currently working on **VidiWaze** — indoor geolocation with Wi-Fi fingerprinting + ML (KNN & Random Forest, 99.5% accuracy)
- 🌱 Currently learning **Embedded Machine Learning & TinyML**
- 👯 Open to collaborate on **ML, Deep Learning and Backend** projects
- 🤝 Looking to explore **Cybersecurity & Pentest**
- ⚡ Former embedded systems intern working on **military-grade applications**
